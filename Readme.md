#WatchStream
 
 NOTE: Production grade


## Made full backend for media upload website with Mongoose using Cloud Hosted Mongodb. Integrated MongoDB Aggregation pipelines to have multiple stages of sorting and filtering in the project.


Dependencies used in the project-

### 1.CORS
To allow only frontend to send the data to the backend

### 2.EXPRESS
All the routing logic is written using express. One of the most famous js library for routing

### 3.JWT
Authentication and Authorization library which allows secure client-side authentication mechanism

### 4.DOTENV
Configure and allows usage of dotenv dependencies.

### 5.AXIOS
Allows requests to be sent to the web and get data. Handles json parsing with advanced features.

### 6.MONGOOSE
ORM Object Relational Mapper for mongo-db and javascript. Allows to interact with mongodb easily plus abstracts query writing process.

### 7.AGGREGATEPAGINATE

Aggregate paginate is the pipeline which allows to make query within query using simple operators 



## INTERESTING POINT- Google DNS used in the Codebase to do DNSlookup in order to mitigate DNS error for connection string of Mongodb while connecting Mongodb hosted in MongoDB Atlas.
